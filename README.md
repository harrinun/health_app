**Patient Medical Record Management System API**
A secure and robust REST API for managing patient medical records in a clinic or hospital, built with FastAPI and structured using Object-Oriented Programming (OOP) principles.

**Project Overview**
This project provides a backend service for a medical records system, offering full CRUD (Create, Read, Update, Delete) functionality for key entities such as Patients, Doctors, Appointments, and Medical Records.
The application is designed with a clean, modular architecture, ensuring separation of concerns between business logic, data access, and API endpoints.
All data is persisted in JSON files, and errors are securely logged to a file to prevent exposing internal application details.

**Key Features**
CRUD Operations: Full data management for Patients, Doctors, Appointments, and Medical Records.
Soft Deletion: Records are never permanently deleted, allowing for data restoration and a complete audit trail.
Background Tasks: Asynchronously sends welcome emails to new patients without blocking the API response.
Structured Logging: All application events and errors are logged to a rotating file (app.log), not the console, for security and persistence.
OOP Architecture: Cleanly organized into services, repositories, and models to promote maintainability and scalability.
Request Validation: Uses Pydantic for robust validation of all incoming request data.
Custom Patient ID Generation: Generates unique, human-readable folder numbers for each patient (e.g., GHA-TM-AAA0001).

**Tech Stack**
Backend: Python 3.11+
Framework: FastAPI
Email: FastAPI-Mail
Data Validation: Pydantic
Server: Uvicorn

Getting Started
Follow these instructions to set up and run the project locally.

1. Prerequisites
Python 3.11 or newer
Git

2. Clone the Repository
git clone https://github.com/harrinun/health_app/new/version2

3. Set Up a Virtual Environment
It's highly recommended to use a virtual environment to manage project dependencies.

On Windows:
python -m venv venv
.\venv\Scripts\activate

On macOS/Linux:
python3 -m venv venv
source venv/bin/activate

4. Install Dependencies
Install all the required packages from the requirements.txt file.
pip install -r requirements.txt

5. Create Environment File (.env)
This application uses a .env file to manage sensitive information like email credentials for sending patient notifications.
Create a file named .env in the root of the project directory and populate it with the following template.
You will need a Google Account with an "App Password" enabled. You cannot use your regular account password.

# Email Configuration for Background Tasks
MAIL_USERNAME=your_google_app_email@gmail.com
MAIL_PASSWORD=your_google_app_password
MAIL_FROM=your_google_app_email@gmail.com
MAIL_PORT=587
MAIL_SERVER=smtp.gmail.com
MAIL_STARTTLS=True
MAIL_SSL_TLS=False

**Security Note:** Remember to add .env to your .gitignore file to prevent committing your secret credentials to version control.

6. Running the Application
Once the setup is complete, you can run the API server using Uvicorn. Make sure you are in the project's root directory (the one containing the health_app folder).
uvicorn health_app.main:app --reload
The API will be available at http://127.0.0.1:8000

API Documentation
Once the server is running, interactive API documentation is automatically generated by FastAPI. You can access it at:
Swagger UI: http://127.0.0.1:8000/docs
ReDoc: http://127.0.0.1:8000/redoc
